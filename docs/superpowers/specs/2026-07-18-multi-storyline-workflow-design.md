# 릴스 워크플로우 고도화 설계 — 다중 스토리라인·게이트 설정·병렬 렌더

- 날짜: 2026-07-18
- 상태: 승인됨 (브레인스토밍 완료)
- 브랜치: feat/reels-editor-v0 이후 작업

## 목표

1. 한 번의 `make` 실행으로 **스토리라인 3개**(설정으로 1~3 조절)를 생성하고,
   게이트에서 **스토리라인×타이틀 조합을 체크박스로 선택**해 여러 mp4를 한 번에 받는다.
2. 게이트에 **⚙︎ 설정 섹션**을 추가한다 — LLM 프로바이더/모델, 자막 크기,
   포인트 컬러, 자막 위치, 배속 등 + **정지 프레임 프리뷰**. 값은 사용자 config에 저장.
3. LLM은 로컬 Claude Code(`claude -p`) 외에 **kimi·gpt 등 OpenAI-호환 API**도
   토큰으로 연결할 수 있다.
4. CLI는 **rich 기반 단계별 진행 표시**로 현재 무엇을 하는지 항상 보여준다.
5. 병렬 실행이 중요하다 — 대본 생성과 렌더 모두 병렬화한다.

## 아키텍처 & 데이터 흐름

```
CapCut 자막 로드
  → [병렬 ×3] LLM 스토리라인 생성 (각기 다른 각도 힌트)
  → 게이트: 스토리라인 3개 + 타이틀 후보, 조합 체크 + 설정 조정 + 프리뷰
  → [병렬] 체크된 조합 렌더
  → manifest.json + 결과 요약 테이블
```

### 병렬화 두 지점

1. **대본 생성** — `ThreadPoolExecutor`(worker 3)로 LLM 호출 3개 동시 실행.
   각 호출에 서로 다른 각도 힌트(정면승부형·반전형·감정선형)를 프롬프트에 주입.
   재시도(최대 2회)는 호출별 독립 — 하나가 실패해도 나머지는 게이트로 진행.
2. **렌더** — 같은 스토리라인의 타이틀 변형은 base.mp4(컷+배속+크롭, 무거움)와
   자막 PNG를 공유하고 타이틀 PNG만 다르다.
   - 스토리라인별 base 렌더를 **스토리라인 단위로 병렬**(동시 ffmpeg 2~3개)
   - 타이틀별 오버레이 패스(가벼움)만 반복
   - 예: 스토리라인 3 × 타이틀 2 = 6개 mp4여도 무거운 렌더는 3번

### 산출물 구조

```
out/<프로젝트-날짜>/
  s1/ edl.json, reel-t1.mp4, reel-t2.mp4, reel.srt, cuts/
  s2/ …
  manifest.json   # 조합·제목·길이·선택 설정 기록 (API 키는 절대 기록 안 함)
```

`render` 재렌더 명령은 스토리라인 폴더(`s1/`) 단위로 동작 — 기존 수동 수정
워크플로우 유지.

## 게이트 UI + 설정/프리뷰

기존 stdlib `http.server` 일회성 게이트를 확장 (다크 테마 유지):

```
🎬 대본 검토
├─ ⚙︎ 설정 (접이식 패널)
│   ├─ AI: 프로바이더 드롭다운 → 모델명 입력 → 키 상태/입력란
│   ├─ 스토리라인 개수 [1~3]
│   ├─ 자막 크기 [28–72] · 타이틀 크기 [48–96]
│   ├─ 포인트 컬러: 타이틀 강조 / 자막 강조 [컬러픽커]
│   ├─ 자막 위치(y_frac) · 자막 박스 투명도 · 배속
│   └─ [프리뷰 갱신] → 정지 프레임 프리뷰 이미지
├─ 스토리라인 카드 ×N (각도 이름 · 총 길이 ±10% 경고 · 5줄 뼈대 · 렌즈
│   · 비트 목록(썸네일) · ☑︎ 타이틀 후보 체크박스)
└─ 결정
    ├─ 피드백 textarea + 재생성 대상 스토리라인 체크
    ├─ [✅ 선택한 N개 조합 렌더] (0개면 비활성)
    └─ [✏️ 선택한 스토리라인 재생성]
```

- **프리뷰**: `/preview?sub_size=…` GET → 실제 영상 추출 프레임 위에 기존
  `render_title_png`/`render_subtitle_pngs` 코드로 합성한 PNG 반환.
  Pillow만 사용(1초 미만). 실물과 동일 코드 경로라 프리뷰=결과.
- **설정 저장**: 승인/재생성 POST에 설정 포함 →
  `~/.config/reels-editor/config.yaml`. 로드 순서:
  `styles/done.yaml`(기본) ← 사용자 config ← CLI 옵션(최우선).
- **모델 변경 적용 시점**: 재생성 시점부터 / 다음 실행부터. 패널에 안내 문구.
- **터미널 폴백**(`--no-ui`): `1-2,3-1` 형식으로 조합 선택. 설정 편집은
  파일 직접 수정 안내.

## LLM 프로바이더 추상화

`storyteller`의 `runner: Callable[[str], str]` 주입점에 꽂는 `llm.py` 신설 —
`build_runner(config) -> Callable[[str], str]`.

| 프로바이더 | 방식 | 모델 예시 |
|---|---|---|
| `claude-cli` (기본) | 로컬 Claude Code `claude -p --model …` | 기본/opus/sonnet/haiku |
| `openai` | OpenAI-호환 REST (`chat/completions`) | gpt-5, gpt-4o … |
| `kimi` | 같은 규격, base_url만 Moonshot | kimi-k2 … |
| `custom` | base_url 직접 입력 | OpenAI-호환 무엇이든 |

- kimi·gpt는 **HTTP 러너 하나**로 처리(base_url·모델명만 차이).
  stdlib `urllib` 사용 — 의존성 추가 없음. 타임아웃 600초.
- 재시도·JSON 추출·EDL 검증은 프로바이더 무관하게 기존 로직 재사용.

### API 키 관리

- 1순위 환경변수(`OPENAI_API_KEY`, `MOONSHOT_API_KEY`).
- 게이트에서 붙여넣기 → `~/.config/reels-editor/credentials.yaml`(chmod 600,
  프로젝트 밖). 로그·manifest에 기록 금지, UI는 `sk-…abcd` 마스킹.
- 설정 패널에 프로바이더별 키 감지 상태 표시(✓ 환경변수 / ✓ 저장됨 / ✗ 없음).

## 모듈 구성

| 모듈 | 변경 |
|---|---|
| `llm.py` (신규) | 프로바이더 러너 팩토리 + OpenAI-호환 HTTP 러너 |
| `config.py` (신규) | 3단 설정 병합, credentials 로드/저장 |
| `storyteller.py` | 각도 힌트 파라미터 + `generate_many()` 병렬 생성 |
| `gate.py` 분리 | `gate.py`(서버·결정) + `gate_html.py`(HTML) + `preview.py`(프레임 합성) |
| `render.py` | base 렌더/타이틀 오버레이 단계 분리 노출, `-progress` 파싱 콜백 |
| `cli.py` | rich 오케스트레이션, 병렬 렌더 큐 |

새 의존성: `rich` 하나.

## CLI 진행 표시 (rich)

- 단계 체크리스트: 자막 로드 → 대본 생성(스토리라인별 스피너/✓/✗) →
  게이트 대기(URL 표시) → 렌더(조합별 진행바, ffmpeg `-progress pipe:` 파싱) →
  완료 요약 테이블(파일·길이·타이틀).

## 에러 처리

- 스토리라인 일부 실패 → 살아남은 것만 게이트에 표시, 실패 사유는 CLI ✗.
  전부 실패 → raw dump 경로와 함께 종료.
- API 러너 HTTP 오류 → 상태코드+응답 요약(키 마스킹) 보고.
- 조합 렌더 하나 실패 → 나머지 계속, 요약에 실패 표시 + exit code 1.
- 프리뷰 실패 → 에러 문구 이미지 반환, 게이트는 계속 동작.

## 테스트 (TDD)

- 단위: config 3단 병합 / HTTP 러너(mock 서버)·키 마스킹 / 각도 힌트 프롬프트 /
  조합 선택 파싱 / 게이트 HTML 스토리라인×타이틀 렌더링 / 프리뷰 합성 구조 검증 /
  manifest 스키마.
- 통합: 합성 영상으로 fake runner 스토리라인 2개 → 조합 3개 병렬 렌더 →
  mp4·srt·manifest 검증.
- 기존 테스트 전부 그린 유지.

## 결정 기록

- 다중 결과물 = 스토리라인 여러 개 + 타이틀 변형 (스타일 변형은 하지 않음)
- 게이트 흐름 = 체크박스 조합 선택 (전부 자동 렌더·순차 선택 안 함)
- 설정 위치 = 브라우저 게이트 내 섹션 (별도 상시 웹앱 안 함 — YAGNI)
- 스토리라인 기본 3개
- 프레임워크 재작성(FastAPI) 기각 — stdlib 게이트 점진 확장
