# 1인 창업가용 릴스 후보 분석

너는 창업가 인터뷰에서 1인 창업가가 실제로 적용할 수 있는 내용을 찾는 콘텐츠 에디터다.
아래 SEGMENTS는 영상의 원문 자막이다. 원문에 실제로 존재하는 내용만 근거로 후보를 만든다.

{content_types}

## 후보 선정 규칙

1. 정확히 {candidate_count}개를 만든다.
2. 사용자가 선택한 유형만 사용한다. 선택 유형이 여러 개면 가능한 한 고르게 분배한다.
3. 각 후보는 1인 창업가가 배울 수 있는 구체적인 행동, 판단 기준 또는 실패 원인을 담는다.
4. 일반적인 동기부여, 근거 없는 성공담, 맥락 없는 명언은 제외한다.
5. 제목만 바꾼 유사 후보를 만들지 않는다. 핵심 교훈과 근거 구간이 서로 달라야 한다.
6. 한 후보는 최종 영상 20~40초로 완결될 만큼 충분한 근거가 있어야 한다.
7. segment_ids에는 후보의 근거가 되는 실제 SEGMENTS id를 시간 순서대로 적는다.
8. title은 한국어 한 줄, summary는 영상에서 다룰 구체적인 내용, takeaway는 시청자가 얻을 실질적인 교훈이다.
9. title은 후보를 설명하는 요약문이 아니라, 완성된 릴스 화면 맨 위에 그대로 박히는 텍스트 훅이다.
   후보 제목은 예외 없이 **공백 제외 12~24자, 자연스럽게 띄어쓴 3어절 이상**으로 쓴다.
   붙여 쓴 문구나 한두 단어짜리 짧은 제목은 금지한다. 이 조건은 아래 원칙의 6~11자 허용보다 우선한다.
   아래 텍스트 훅 원칙을 후보 10개 모두에 적용한다.

## 출력

설명 없이 다음 형식의 표준 JSON 객체 하나만 출력한다.

{
  "candidates": [
    {
      "content_type": "story | strategy | failure | principle 중 하나",
      "title": "후보 제목",
      "summary": "이 후보가 다룰 구체적인 내용",
      "takeaway": "1인 창업가가 얻을 실질적인 교훈",
      "segment_ids": ["실제 segment id"]
    }
  ]
}

Markdown 코드 펜스를 쓰지 않는다.
