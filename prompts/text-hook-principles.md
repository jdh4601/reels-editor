## 목표

창업가가 자기 문제처럼 느끼고, 결론이 궁금해 스크롤을 멈추는 **두 줄짜리 텍스트 훅**을 만든다.
내용을 다 말하는 요약문이 아니라 `익숙한 전제 + 예상 밖의 빈틈`을 약속하되, 릴스가 실제로 답하는
범위 안에서만 호기심을 만든다.

## 두 줄 설계

1. 모든 생성 제목은 공백 제외 12~24자, 자연스럽게 띄어쓴 3어절 이상으로 쓴다. 모델 응답에는
   줄바꿈을 넣지 않고 한 줄로 직렬화한다. 렌더러가 두 줄로 나눠 표시한다.
2. 제목을 만들 때부터 **첫 줄은 대상·상황·통념**, **둘째 줄은 반전·위험·판단 기준·행동**이 되도록
   두 의미 덩어리로 설계한다. 첫 줄만 읽으면 다음 말이 궁금하고, 둘째 줄을 읽으면 영상에서 얻을
   효용이 보여야 한다.
3. 두 덩어리가 자연스러운 어절·구절 경계에서 갈리도록 쓴다. 첫 줄이 `그런데`, `이것`, `그 이유`처럼
   맥락 없는 낚시만 남거나, 둘째 줄이 첫 줄을 단순 반복하면 안 된다.
4. 창업가의 현실적인 관심사인 제품, 마케팅, 고객, 채용, 공동창업자, 성장, 실패, 생존, 의사결정 중
   실제 발화의 핵심과 맞는 소재를 앞세운다.

## 검증된 훅 유형

- **통념 반박형**: 널리 믿는 조언이나 상식을 문제 삼아 숨은 맹점을 연다.
  예: `1인 창업가들에게 / 가장 과대평가된 조언`
- **긍정→부정 반전형**: 첫 줄의 강점·성과를 둘째 줄의 실패·한계와 충돌시킨다.
  예: `마케팅은 훌륭한데 / 망하는 브랜드의 특징`, `완벽한 앱도 / 마케팅이 최악이면 끝이다`
- **우선순위 전복형**: 모두가 먼저 한다고 믿는 일보다 더 중요한 것을 예고한다.
  예: `제품을 만드는 것보다 / 훨씬 중요한 창업가의 자질`
- **판단 기준 공개형**: 어려운 선택에서 가장 먼저 볼 기준 하나를 약속한다.
  예: `공동창업자를 찾을 때 / 가장 먼저 봐야하는 것`
- **구체적 행동형**: 당장 실행할 수 있는 단호한 행동이나 좁은 목표를 제시한다.
  예: `미친듯이 만들어서 / 뭐라도 보여줘야 한다`, `고객 딱 100명만 / 확실히 만족시키자`
- **성공 경계형**: 좋은 결과가 커질수록 생기는 역설적인 위험을 예고한다.
  예: `창업자가 성공할수록 / 조심해야 하는 이유`

여러 후보를 만들 때는 후보끼리 다른 훅 유형을 사용한다. 실제 근거가 있다면 최소 하나는
통념 반박형, 긍정→부정 반전형, 우선순위 전복형 중에서 고른다. 같은 문장의 단어 순서만 바꾼
유사 후보는 만들지 않는다.

## 문장과 사실성

1. 스타카토로 끊고, 빼도 뜻이 같은 조사·수식어만 덜어낸다. 실제 순위·성과·비교를 주장하는
   수식어는 발화의 근거를 지킨다. 아래의 수사적 수치와 비유는 제목의 표현 기법으로 적극 사용한다.
2. 명사구나 `특징`, `자질`, `조언`, `이유`, `기준`, `선택`처럼 답을 예고하는 말로 끝내는 형태를
   우선한다. 특히 단순한 `~한다`보다 원인과 판단 기준이 궁금해지는 `~하는 이유`를 적극 사용한다.
   `~하지 마세요`, `~부터 하세요` 같은 짧고 단호한 행동문·경고문도 적극 사용한다.
3. 시청자가 모르는 브랜드명·제품명·전문용어는 뺀다. 꼭 필요하지 않은 회사 이름은 `첫 고객`,
   `직원 셋`, `공동창업자`처럼 누구나 바로 이해하는 말로 바꾼다.
4. 원문에 없는 실제 성과, 금액, 고객 수, 실패 결과, 비교, 최상급을 사실처럼 만들지 않는다.
   단, 원문이 말하는 `대부분`, `흔한 실수`를 강조하는 제목의 수사적 `99%`는 허용한다.
   이 표현을 실제 조사·통계·성공률로 취급하거나 대본·캡션의 사실 수치로 옮기지 않는다.
5. 제목이 만든 질문이나 약속은 선택한 릴스 안에서 반드시 회수되어야 한다.

나쁜 예: `성공하는 방법을 알려드립니다` (긴장과 구체성이 없음),
`이것 때문에 모든 창업가가 망한다` (근거 없는 공포·최상급),
`Notion으로 온보딩 자동화` (낯선 제품명이 먼저 나오고 반전이 없음).

## 공감과 공유를 유도하는 제목 (우선 적용)

제목을 읽은 창업가가 `설마?`, `혹시 나도 해당하나?`, `내 상황인데?`, `이거 내 얘기다`,
`이거 내 친구 얘기다` 중 하나를 떠올리게 한다. 구체적인 행동·막힘·실패 상황을 먼저 보여주고,
원인·해결책·결과의 전부는 공개하지 않는다. 실제 릴스 안에서 궁금증을 해소할 수 있어야 한다.

- **행동 공감형**: `만드는 데 취해 / 고객을 안 만나는 대표들`
- **실패 상황형**: `제품을 만들었는데 / 아무도 안 살 때`
- **위로·전환형**: `출시 후 반응 없어 / 속상한 창업가에게`
- **특징·자기 점검형**: `고객 만나기를 미루는 / 창업가의 특징`
- **경험·결과형**: `고객을 만나기 시작했더니 / 달라진 것`
- **구체적 방법형**: `첫 고객을 만나러 가는 / 한 가지 방법`
- **순서 반전형**: `순서를 거꾸로 해서 / 막히는 창업가들`
- **욕심 경계형**: `콘텐츠 하나에 / 모든 걸 담지 마세요`

예시는 문장 구조를 참고하는 용도다. 주어진 릴스에 없는 실패, 해결책, 인과관계는 가져오지 않는다.
원문이 대부분의 창업자가 순서나 우선순위를 잘못 잡는다고 말한다면
`99%의 창업자가 / 순서를 거꾸로 하는 이유`처럼 수치를 과감하게 써도 된다.
`망한다`는 결과는 실제 릴스에서 다룰 때만 쓴다. 개인 한 명의 경험만으로 대부분의 창업자에게
해당한다고 확대하지 않는다.
대상을 비하하거나 실패한 시청자를 탓하지 않는다. `콘텐츠 하나로 하나로` 같은 중복은 제거한다.

제목을 고르기 전 내부적으로 확인한다 (평가 과정은 출력하지 않는다):
1. 어떤 창업가의 어떤 현실적인 행동·상황을 짚는가?
2. 시청자가 자신이나 특정 동료·친구를 떠올릴 수 있는가?
3. 영상에서 확인할 원인·판단 기준·다음 행동에 대한 궁금증이 남는가?
4. 제목의 약속을 선택한 영상의 실제 발화로 회수할 수 있는가?

길이·사실성 규칙을 충족한 후보 중 자기 상황으로 느껴지고 공유할 대상이 떠오르는 제목을 우선한다.

## 과감한 표현과 호기심 (우선 적용)

- **수치 강조형**: `대부분의 창업자가 실수한다`를 `99%의 창업자는 / 거꾸로 한다`처럼 바꾼다.
  실제 발화가 흔한 실수나 잘못된 순서를 설명할 때 사용한다. 수사적 수치의 허용 범위는 위 규칙을 따른다.
- **이유 궁금증형**: `~한다`로 결론을 끝내기보다 `~하는 이유`로 바꿔 원인과 판단 기준을 열어 둔다.
  예: `잘 만든 제품도 / 아무도 안 사는 이유`, `창업가가 고객을 / 먼저 만나야 하는 이유`.
  영상에 이유가 없다면 억지로 이유형을 쓰지 않는다.
- **호기심 비유형**: 사업의 핵심 원리를 스포츠, 마라톤 같은 익숙한 장면에 연결한다.
  예: `회사를 만드는 건 / 스포츠를 하는 것과 같다`, `사업은 마라톤인데 / 전력 질주하는 대표들`.
  원문에 비유가 없어도 실제 교훈을 정확히 설명하는 편집자의 비유는 허용하되,
  화자가 직접 한 말처럼 인용하지 않는다. 흔한 명언으로 끝내지 말고 비유 속의 의외의 연결이나
  실수를 남겨 영상에서 이유를 확인하고 싶게 한다.
- **단정적 경고형**: `~하지 마세요`, `~부터 하세요`, `~에 욕심내지 마세요`처럼 힘 있는 어조를 쓴다.
  예: `고객을 만나기 전에 / 제품부터 만들지 마세요`, `콘텐츠 하나에 / 모든 걸 담지 마세요`.
  영상의 조언과 적용 조건에 맞게 대상을 좁힌다.

후보마다 수치·이유·비유·경고를 모두 넣지 않는다. 실제 핵심에 가장 잘 맞는 표현을 골라
공감, 자기 점검, 친구에게 공유하고 싶은 마음과 호기심을 함께 만든다. 기존 두 줄·길이 규칙은 유지한다.
