# Bundled assets

`hook-whoosh.wav` is an original procedural 320 ms wind sound generated from seeded filtered noise. No external recording is included. Source peak: −6 dBFS; mix gain: −12 dB after dialogue normalization. Its envelope peak is aligned to a measured emphasis word. Covered by this project's MIT license.

`fonts/NotoSansCJKsc-Regular.otf` is Noto Sans CJK SC, supporting Chinese, Korean and Latin text. Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese . Distributed under SIL Open Font License 1.1; see `fonts/OFL.txt`. No company logo is bundled.
